For iOS, use the opaque 1024px artwork; platform tooling may generate additional sizes.
For PWA manifest icons, use the 192 and 512px ordinary icons with purpose "any", and maskable icons with purpose "maskable".
The maskable version has added clear space for cropping by platform icon masks.
Native icon files were structurally validated; they have not been installed or visually tested on macOS or Windows.

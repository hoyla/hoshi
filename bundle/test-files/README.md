# Translation test files

Five published source-language excerpts about Earth, each supplied as a DOCX and a native text PDF.
Each DOCX/PDF pair contains the same excerpt. The five language editions provide different excerpts, not a sentence-aligned parallel corpus.

## Source and reuse

Source: the corresponding language edition of Wikipedia. Authors: the contributors listed in each article history.
All excerpts are distributed under Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0).
Licence: https://creativecommons.org/licenses/by-sa/4.0/
Wikimedia reuse terms: https://foundation.wikimedia.org/wiki/Policy:Terms_of_Use#7._Licensing_of_Content

The article bodies use published source-language prose; no new prose or machine translations were generated for them. Excerpts were selected at sentence boundaries and reformatted.
References, images, navigation and template captions were omitted; invisible reference separators and whitespace were normalised.
The Arabic extract also omits an empty symbol annotation produced by the source text-extraction API.
The Spanish extract omits a sentence introducing a quotation absent from the API response; its source also credits the English Wikipedia article and contributors.

Word counts below count whitespace-separated body tokens containing a letter or digit. Titles, section headings and attribution are excluded.
Arabic and Hebrew use right-to-left paragraph direction. The PDFs have embedded fonts and text, with no scanned page images.

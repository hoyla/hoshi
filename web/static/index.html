      What is this?

      A tool for translating documents on this computer alone. It needs no internet and sends nothing anywhere: the document, the translation and everything about them stay on this Mac. It is meant for material that must not leave the newsroom.

      Two translators, and which to pick

      It offers two, because they are good at different things. Pick on the page whichever suits the document.

      • TranslateGemma gives the better translation, as plain text without the document's layout. Use it when the exact words matter. It runs in the Ollama app.
      • LibreTranslate keeps the layout and hands back the same kind of file, quickly — enough to see what a document is about. It is weak on Arabic and Hebrew. It runs in Docker Desktop.

      If a translator says “not available”

      What to do:

      • TranslateGemma not available. The Ollama app isn't running. Open Ollama from Applications, wait a few seconds, then reload this page.
      • The page won't open at all. This page itself runs in Docker Desktop, so if Docker is off there is nothing to open. (You are reading this, so Docker is running on this computer.) If a colleague's page won't open, Docker Desktop on their computer isn't running: they should open Docker Desktop from Applications, wait until it says it is running, then open the page again. A colleague whose tool is working can translate for them in the meantime.

      What is kept, and what is not

      • Every translation is saved in (, then in Finder press ⌘⇧G and paste to open it), each with a small record of how it was made. These are kept until you delete them yourself; the tool never removes or overwrites one.
      • The document you upload is held only in memory while it is worked on. It is never written to disk, and it is gone within a few hours or as soon as Docker restarts.

      Putting this on another offline computer

      The installer is built on a Mac that does have internet, then carried across — it cannot be built on an offline computer. In short:

      1. On a connected Mac, get the project's code (clone its repository).
      2. Build the installer bundle by following the repository's README (the build-bundle.sh script).
      3. Copy the finished bundle onto a USB stick.
      4. Copy it from the stick onto the offline computer and run install.sh, as the bundle's own README.txt describes.
